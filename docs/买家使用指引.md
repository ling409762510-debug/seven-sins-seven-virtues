# 七宗罪 | 七美德 · 使用指引

## 开始测试

1. 打开卖家发送的测试链接（正式发布后使用 GitHub Pages 网址）。
2. 输入测试码 **SEVEN2026**，点击“开启档案”。
3. 输入昵称、阅读简短说明，按照最近一个月的日常反应完成 30 道题。
4. 点击答案自动前进，无需点击“下一题”；也可以返回上一题修改，原选择会保留。第 10、20、30 题后会显示阶段小结。
5. 完成后查看十四维雷达、逐项解读和行动建议。

建议预留约 4–6 分钟，不需要赶时间。答案没有对错。

## 暂停与继续

同一浏览器会自动保存当前进度。重新打开原链接即可继续。

更换手机、浏览器，使用无痕模式或清理浏览器数据，可能无法找回记录。若页面提示无法保存，请保持页面开启直至完成，并保存报告图片。

## 保存报告

- “保存结果摘要图”：生成主导倾向和十四维雷达摘要。
- “保存完整报告图”：生成 13 张分段报告图片，逐张保存即可。
- 手机：长按图片保存到相册；电脑：点击图片下方的下载链接。
- 若应用内浏览器无法保存图片，可截图保存，或在系统浏览器重新打开链接测试。不同浏览器之间不会同步答题记录。

## 重新测试

测试码可以重复使用。点击“重新测试”并确认后，会替换当前浏览器中的旧记录。建议先保存上一份报告。

## 如何理解结果

这是娱乐型自我觉察测试，不是心理诊断或道德评价。主导倾向只比较你自己的各项分数，不代表你在人群中的位置。七宗罪与七美德各自计分，可以同时较高，也可以同时较低。

结果随近期状态和回答变化而变化。把它作为观察自己的一个入口即可。
